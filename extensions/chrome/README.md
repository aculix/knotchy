# Open in Knotchy (Chrome extension)

Adds **Open in Knotchy** to the right-click menu of links in Chrome (and other Chromium
browsers such as Edge, Brave and Arc).

Chrome gives the macOS Services menu only a link's words, never its address, so Services
can't open Chrome links in Knotchy. This extension hands the address to the Knotchy app
through its `knotchy://open?url=…` URL scheme instead. It only passes on `http` and
`https` links, and it needs no permission beyond adding the menu item.

## Install

1. Open `chrome://extensions` and turn on **Developer mode**.
2. Click **Load unpacked** and choose this folder.
3. Right-click any link and choose **Open in Knotchy**. The first time, Chrome asks
   whether to open Knotchy; allow it.

The Knotchy app must be installed.

## Publishing

[STORE.md](STORE.md) has everything the Chrome Web Store asks for: the package, listing text, graphics and privacy
answers. Once the store assigns the item ID, set `ChromeExtension.storeURL` in the app and link the listing here.

## Files

- `manifest.json`: Manifest V3, with the `contextMenus` permission only
- `background.js`: creates the menu item and opens the `knotchy://` link
- `icons/`: generated by `scripts/make-icons.sh` at the repository root
- `store/`: the store's promo images (also generated) and framed screenshots; not part of the package
